# Remove nonlocal state from _print_ls_tree closure

## Description

query.py:670,678 use 'nonlocal printed_count' inside the recursive tree printer nested in _handle_ls. The project style rules explicitly forbid nonlocal. The closure also reads seven other names from the enclosing scope (args, context_parents, filtered_ids, all_tickets, tickets_dir, args.sort, prefix), which makes it untestable. Fix: extract a small TreePrinter dataclass that holds the shared state (counter, filter set, tickets dict, sort key) and exposes a print(tid, prefix, is_last) method; _handle_ls instantiates and drives it.
