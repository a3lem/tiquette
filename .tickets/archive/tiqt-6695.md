# Use argparse type=int, choices=range(5) for --priority

## Description

_fields.VALID_PRIORITIES (commands/_fields.py:13) is ('0','1','2','3','4') used as argparse choices, then int() is called later in namespace_to_field_changes (_fields.py:63). The CLI design treats priority as an int everywhere else. Fix: declare 'type=int, choices=range(5)' in the argparse setup, drop VALID_PRIORITIES, and remove the int() conversion.
