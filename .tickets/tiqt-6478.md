# Memoize _subtree_depth

## Description

query._subtree_depth (query.py:441-451) recurses over the dep tree without memoization, so for siblings sharing subtrees the cost is exponential. Currently fine on small ticket sets but a real cliff. Fix: pass a 'memo: dict[str, int]' through the recursion (or wrap with functools.cache via a frozen closure).
